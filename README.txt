LINGUA version 2.1 — camera / microphone recovery update

今回追加したもの
- 日本語 ⇄ 英語の切り替え
- テキスト翻訳
- 写真から英文を読み取るOCR（Tesseract.js）
- 「今から撮影」と「アルバムから選択」を別ボタンに分離
- マイク拒否時の設定案内と再試行ボタン
- マイク音声の文字起こし（Web Speech API対応ブラウザ）
- 翻訳文の読み上げ
- 翻訳履歴（同じブラウザ内）
- 「＋ より詳しく」の文型・文法の学習ガイド
- ダーク基調のシンプルな画面

使い方
1. ZIPを展開します。
2. HTTPS対応のWebホスティング（GitHub Pagesなど）にフォルダ内のファイルを配置します。
3. iPhoneのSafariで公開URLを開き、共有ボタン →「ホーム画面に追加」。

注意
- これは動作確認用の試作版です。MyMemoryの翻訳APIを利用するため、通信が必要で、利用制限や翻訳品質のばらつきがあります。
- OCRはTesseract.jsをCDNから読み込むため、初回利用時に通信が必要です。印刷された文字の方が認識しやすく、手書き文字は苦手です。
- 音声認識はブラウザ依存です。iPhoneのSafariでは利用可否や挙動が環境によって異なります。使えない場合はiOSキーボードの音声入力を利用してください。
- 「会話を聞き取る」はマイクから連続して音声を文字起こしする簡易機能です。会話の話者分離や自動翻訳のリアルタイム字幕には未対応です。
- 文型・品詞の自動判定はまだ簡易ガイドです。SV/SVC/SVO/SVOO/SVOCを正確に判定するAI解析は未実装です。
- APIキーをブラウザに埋め込まない設計にするため、将来の高精度AI解析には別途バックエンドが必要です。
- マイク利用はブラウザの許可が必要です。拒否した場合はiPhoneの設定またはSafariのサイト設定で許可を変更し、LINGUAに戻って再試行してください。アプリからOSの拒否設定を強制解除することはできません。
